# Diabetic Retinopathy Detection

AI-powered patient risk stratification from retinal fundus images.

Upload a retinal scan → get a severity classification (No DR / Mild / Moderate / Severe / Proliferative) with confidence score.

**Model:** EfficientNetB3 fine-tuned on APTOS 2019 dataset  
**Validation accuracy:** ~74%  
**Built by:** Priyanka Raghunathan
